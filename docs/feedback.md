### 반영 내용

**1. 효과음 리듬화**
- 음높이: C5~C6 한 옥타브 펜타토닉을 올라갔다 내려오는 프레이즈로 순환
- 리듬: 4박마다 첫 박에 강세(더 크게 + 낮은 루트음)
- 연속성: 콤보 10 이상 하이햇, 25 이상 첫 박 베이스, 50 이상 5도 화음이 더해짐

**2. 문항마다 소리 초기화**
- 숫자·수식·계산 모드에서 새 문항이 나오면 프레이즈가 첫 음부터 시작. 콤보 숫자는 유지
- 계산 모드 숫자 입력에도 여린 타건음 추가

**3. 콤보 연출 위치**
- "N COMBO!" 배지가 콤보 숫자 오른쪽에서 가로로 튀어나왔다 사라짐(세로 이동 없음)
- 진행 바가 한 번 반짝임

**4. 속도 측정과 점수**
```
정타 1개 점수 = 기본점 × 속도계수 × 콤보배율
속도계수 = clamp(목표시간 / 걸린시간, 0.5, 2.0)
콤보배율 = 1 / 1.5(10+) / 2(25+) / 3(50+)
오타·오답 = 0점 + 콤보 끊김
```
| 모드 | 단위 | 기본점 | 목표시간 |
|---|---|---|---|
| 키 위치 | 키 1개 | 10 | 0.6초 |
| 숫자·수식 | 글자 1개 | 10 | 0.3초 (문항 첫 글자 0.9초) |
| 빠른 계산 | 정답 1문제 | 50 | 쉬움 3초 · 보통 5초 · 어려움 8초 |

- 연습 중 화면: 점수, 속도(타/분, 계산은 초/문제), 정확도를 실시간 표시. 정타마다 `+점수`, 매우 빠르면 ⚡
- 결과 화면: 총점을 크게 표시, "최고 점수 갱신" 연출
- 기록 화면: 그래프·최고 기록·세션 표에 점수 반영. 점수 도입 전 기록도 오류 없이 표시
- 계산 모드 속도는 맞힌 문제의 키만 셈(Backspace·오답 입력 제외)

**함께 고친 것**: 결과 화면 이모지 애니메이션 중 잠깐 생기던 가로 스크롤

## 2차 사용자 테스트 — 2026-10-08

### 피드백 요약

| # | 피드백 | 원인 분석 | 결정 |
|---|---|---|---|
| 1 | 결과·점수 화면에서 어떤 모드의 어떤 설정으로 했는지 보고 싶다 | 결과 화면에 모드 이름만 있고 난이도·길이·넘패드 표시 여부는 없었음 | 결과 제목 아래에 설정 칩 줄 추가 |
| 2 | 메인 페이지에 개인 최고기록을 작게 보여 달라 | 홈에는 모드별 최고 타/분만 있었고, 설정이 달라도 한데 섞여 비교 기준이 없었음 | 홈 칩 줄에 `🏅 개인 최고 N점` 추가 |
| 3 | 다른 사람과 형평성을 맞추도록 기록 기준을 **수식 입력 · 어려움 · 60초 · 화면 넘패드 숨기기**로 | 기록에 화면 넘패드 표시 여부가 저장되지 않아 4번째 조건을 판정할 수 없었음 | 기록에 `showKeypad` 저장, 4가지 조건이 모두 맞는 기록만 개인 최고로 인정 |

### 반영 내용

**1. 결과 화면 설정 표시**
- 칩 순서: 모드 → 난이도(키 위치는 레벨) → 길이(`30타`·`10문항` 또는 `60초 타임어택`) → `넘패드 보기/숨김`
- 공식 기준 기록이면 `🏅 공식 기록`, 이전 공식 최고 점수를 넘으면 `🏅 개인 최고 갱신` 칩이 붙음

**2. 공식 개인 최고기록**
- 기준: `mode=expr`, `difficulty=hard`, `lengthType=time`, `showKeypad=false` (`js/core/stats.js`의 `OFFICIAL`)
- 지표: 점수 (속도·정확도·콤보를 합친 1차 피드백의 점수)
- 홈: 기록이 있으면 `🏅 개인 최고 N점`, 없으면 기준만 작게 표시
- 넘패드 표시 여부가 없는 이전 기록은 숨겼는지 확인할 수 없어 공식 기록에서 제외

**3. 개인 최고(공식)와 연습 최고(모드별) 구분**
- 기록은 그대로 한 목록에 저장하고, 공식 여부는 조회할 때 판정한다
- **개인 최고**: 공식 기준 기록끼리 점수로 비교. 갱신하면 결과 제목 `🏅 개인 최고 갱신!`(처음이면 `첫 공식 기록!`)과 색종이·효과음
- **연습 최고**: 같은 모드면 설정과 상관없이 비교하는 기존 기록. 홈 모드 카드, 기록 화면 카드, 결과 제목(`연습 최고 점수 갱신!` 등)에 `연습 최고`라고 표시하고 색종이는 없음
- 이유: 둘 다 "최고"라고 부르면 쉬운 설정으로 낸 기록이 축하받고, 정작 공식 기록 갱신은 묻힐 수 있음

### 검증
- 단위 테스트 39개: 공식 기준 4가지 중 하나라도 다르거나 넘패드 정보가 없으면 제외, 공식 기록 중 최고 점수 선택, 설정 라벨
- E2E: 결과 화면 설정 칩, 홈에서 수식·어려움·타임어택·숨김으로 실제 한 판 → `개인 최고 갱신` 칩 → 홈에 같은 점수 표시
- 참고: 이 환경에서는 E2E `콤보 마일스톤 배지` 단계가 변경 전 코드에서도 실패함(헤드리스 Chrome이 그 시점에 프레임을 그리지 않아 애니메이션이 0프레임에 멈춤). 그 단계를 뺀 나머지 17개 통과

### 추가 요청 — 상단 숫자키 ON/OFF

| 요청 | 결정 |
|---|---|
| 상단 숫자키(키보드 맨 윗줄)를 켜고 끌 수 있게 | 넘패드는 항상 사용 가능, **상단 숫자키만** 설정으로 켜고 끔(기본 꺼짐) |

- 홈 옵션 `상단 숫자키` 줄, 넘패드 `.` 키로 전환
- 켜면 메인 키보드의 숫자 · `.` · `-` · `/` · Enter와 Shift+8(`*`), Shift+=(`+`)도 입력으로 받음
- 꺼져 있으면 지금처럼 경고만 띄우고, 홈에서 켤 수 있다고 안내
- 기록과 결과 칩에 `상단 숫자키` 사용 여부를 남김
- **공식 개인 최고는 입력 키 상관없이 인정**: 상단 숫자키는 손 이동이 크고 연산자에 Shift가 필요해 넘패드보다 유리하지 않음
