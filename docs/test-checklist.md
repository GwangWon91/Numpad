# 테스트 체크리스트

자동 테스트(`npm test`, `npm run test:e2e`)로 확인하기 어려운 것을 실제 키보드로 점검합니다.

## 자동 테스트가 다루는 범위

| 구분 | 내용 |
|---|---|
| 단위 26개 | 입력 정규화, 문제 생성(시드·형식·정답 검산), 세션 판정·콤보·종료, 통계, 저장소 |
| E2E 15개 | 네 가지 모드 완주, 오타 집계, 결과 가드, NumLock/상단 숫자키 경고, 타임어택, 최고 기록 연출, 기록 화면·필터, 새로고침 유지, 다크 모드, 모바일 너비 |

## 실제 키보드 수동 점검

### 입력
- [ ] NumLock을 끈 상태에서 숫자 키를 누르면 "NumLock이 꺼져 있어요" 경고가 뜬다
- [ ] NumLock을 다시 켜면 경고가 사라지고 정상 입력된다
- [ ] 상단 숫자키로 입력하면 오타로 세지 않고 "넘패드로 입력" 경고만 뜬다
- [ ] 키를 길게 눌러도 한 번만 입력된다
- [ ] 빠르게 연타해도 입력이 빠지거나 두 번 들어가지 않는다
- [ ] `/` 키가 브라우저 빠른 찾기를 열지 않는다
- [ ] 마우스로 버튼을 누른 뒤 넘패드 Enter를 눌러도 버튼이 한 번 더 눌리지 않는다

### 흐름
- [ ] 홈에서 넘패드만으로 모드 선택(1~4), 레벨·난이도(+ −), 길이(*), 넘패드 표시(/), 시작(Enter), 기록(0)이 된다
- [ ] 연습 중 Esc로 홈에 돌아가면 기록이 저장되지 않는다
- [ ] 결과 화면이 뜨자마자 누른 Enter로는 재시작되지 않는다
- [ ] 다른 탭에 갔다 와도 타이머가 정상이다 (타임어택은 시간이 흐른 만큼 끝나 있음)

### 재미와 디자인
- [ ] 콤보가 오를수록 효과음 음높이가 올라간다
- [ ] 10, 25, 50 콤보에서 "COMBO!" 연출과 효과음이 나온다
- [ ] 최고 기록을 갱신하면 색종이와 축하 문구가 나온다
- [ ] 효과음 끄기, 테마(시스템/라이트/다크) 전환이 새로고침 후에도 유지된다
- [ ] 운영체제의 "애니메이션 줄이기"를 켜면 움직임이 최소화된다

### 환경
- [ ] Chrome 최신, Edge 최신
- [ ] 1366×768 노트북 화면에서 연습 화면이 스크롤 없이 대부분 보인다
- [ ] GitHub Pages 주소에서 새로고침해도 404가 나지 않는다 (해시 라우팅)
