# 요구사항 명세 — 넘패드 익숙해지기

> 0단계 산출물 · 작성일 2026-10-01

## 1. 목적

**넘패드에 익숙해지고, 숫자와 계산을 빠르게 입력한다.** 이것이 이 도구의 본분이다.

- 넘패드를 보지 않고 치는 감각, 숫자열과 수식을 빠르고 정확하게 입력하는 습관을 기른다.
- **재미있고 예쁘게** 만들어서 자꾸 하고 싶게 한다(콤보, 레벨, 효과음, 부드러운 애니메이션).
- SKCT 같은 계산기 활용 시험은 동기이자 참고 사례일 뿐이다. 기능 결정은 "넘패드 숙련과 빠른 계산에 도움이 되는가"를 기준으로 한다.

개인 연습용 도구이며 GitHub Pages로 배포한다.

## 2. 참고 사례: SKCT 응시 환경

> 동기가 된 사례로만 참고한다. 여기서 뽑은 시사점 중 일반적인 넘패드 숙련에도 도움이 되는 것만 기능에 반영한다.

| 항목 | 조사 내용 | 연습 도구에 반영할 점 |
|---|---|---|
| 필기 도구 | 종이 사용 금지. 프로그램이 제공하는 **계산기, 메모장, 그림판**만 사용 가능 | 계산기 입력과 중간값 메모를 모두 연습 |
| 창 전환 | 계산기와 풀이 화면 사이를 전환하는 전용 단축키가 없음. **마우스로 전환**하는 방식에 익숙해지라는 조언이 많음 | 손이 마우스 → 넘패드 → 마우스로 오가는 흐름을 연습에 포함(Could) |
| 키보드 | 노트북 키보드로도 응시할 수 있지만, 수리 영역은 넘패드가 있는 키보드가 효율적이라는 의견이 많음 | 넘패드(`Numpad*` 코드) 입력만 정답으로 인정하고, 상단 숫자키 입력은 경고 |
| 시간 압박 | 인지역량은 언어, 수리, 직군별 역량을 합쳐 약 60문항을 75분 안에 풂. 수리 난도가 높다는 평이 많음 | 속도(KPM)와 정확도를 함께 기록. 제한 시간 모드 제공 |
| 수치 형태 | 표/그래프 해석형 문제에서 금액, 비율(%), 소수점, 증감률 계산이 잦음 | 소수점과 여러 자릿수 숫자, 연산자 조합 문제 생성 |

**미확인 사항**: 내장 계산기의 정확한 UI(표준 계산기인지, 수식 입력을 지원하는지, 키보드 입력을 받는지)는 공개 자료로 확정할 수 없었다. 응시 전 **시스템 점검 화면에서 직접 확인**하고, 결과에 따라 계산 입력 모드를 조정한다.

## 3. 연습 대상 키 범위

```
┌─────┬─────┬─────┬─────┐
│ Num │  /  │  *  │  -  │
├─────┼─────┼─────┼─────┤
│  7  │  8  │  9  │     │
├─────┼─────┼─────┤  +  │
│  4  │ [5] │  6  │     │   [5] = 홈 포지션(돌기)
├─────┼─────┼─────┼─────┤
│  1  │  2  │  3  │     │
├─────┴─────┼─────┤Enter│
│     0     │  .  │     │
└───────────┴─────┴─────┘
```

- 필수: `0-9`, `.`, `+ - * /`, `Enter`
- 보조: `Backspace`(넘패드 밖이지만 계산기 수정용), `NumLock` 상태 감지
- 권장 손가락 배치: 검지 4·7·1, 중지 5·8·2·`/`, 약지 6·9·3·`.`·`*`, 새끼 `-`·`+`·`Enter`, 엄지 0

## 4. 사용자 스토리

1. 나는 **눈으로 키보드를 보지 않고** 넘패드 각 키를 누를 수 있도록 키 위치를 단계별로 익히고 싶다.
2. 나는 `38450`, `12.75` 같은 **여러 자릿수와 소수점이 섞인 숫자**를 틀리지 않고 입력하고 싶다.
3. 나는 `1250*0.15+320` 같은 **수식을 연산자 키까지 포함해** 끊김 없이 입력하고 싶다.
4. 나는 연습 후 **속도와 정확도**를 바로 확인하고 싶다.
5. 나는 **자주 틀리는 키**가 무엇인지 알고 싶다.
6. 나는 날짜별 기록을 보며 **실력이 늘고 있는지** 확인하고 싶다.
7. 나는 실수로 **상단 숫자키를 쓰거나 NumLock이 꺼져 있으면** 바로 알림을 받고 싶다.
8. 나는 시험처럼 **제한 시간 안에** 연습하고 싶다.

## 5. 기능 요구사항

| ID | 기능 | 우선순위 | 관련 스토리 |
|---|---|---|---|
| F1 | 키 위치 익히기 모드(레벨 1~4: 홈 행 → 위/아래 행 → 0과 `.` → 연산자와 Enter) | Must | 1 |
| F2 | 숫자열 타이핑 모드(자릿수와 소수점 여부로 난이도 조절, Enter로 제출) | Must | 2 |
| F3 | 계산 입력 모드(제시된 수식을 그대로 입력) | Must | 3 |
| F4 | 화면 넘패드 표시 및 키 입력 시각 피드백 | Must | 1, 5 |
| F5 | 세션 결과: KPM, 정확도, 소요 시간 | Must | 4 |
| F6 | 넘패드가 아닌 입력과 NumLock 꺼짐 경고 | Must | 7 |
| F7 | 기록 저장(localStorage) 및 기록 화면 | Must | 6 |
| F8 | 틀린 키 히트맵 | Should | 5 |
| F9 | 날짜별 추이 그래프 | Should | 6 |
| F10 | 제한 시간 모드(60초 등) | Should | 8 |
| F11 | (F16으로 통합) | — | — |
| F12 | 기록 JSON 내보내기와 초기화 | Could | 6 |
| F13 | 마우스 클릭과 넘패드 입력을 오가는 전환 훈련 | Could | — |
| F14 | 라이트/다크 테마 | Should | — |
| F15 | 재미 요소: 콤보 카운터, 정답/오답 효과음(끄기 가능), 키 누름 애니메이션 | Must | 1~3 |
| F16 | 빠른 계산 모드: 간단한 사칙연산 결과를 넘패드로 바로 입력(암산+입력 속도) | Should | 3 |
| F17 | 개인 최고 기록 갱신 축하 연출 | Should | 6 |

## 6. 비기능 요구사항

| ID | 항목 | 기준 |
|---|---|---|
| N1 | 반응성 | 키 입력부터 화면 피드백까지 체감 지연이 없어야 함(16ms 이내 목표) |
| N2 | 오프라인 | 서버 없이 정적 파일만으로 동작하고, 외부 의존성을 최소화함 |
| N3 | 환경 | 데스크톱 Chrome/Edge 최신 버전 우선. 모바일은 안내 문구만 표시 |
| N4 | 개인정보 | 모든 데이터는 브라우저 로컬에만 저장함 |
| N5 | 유지보수 | 빌드 도구 없는 순수 HTML/CSS/JS(ES Modules), 모듈별 단일 책임 |
| N6 | 디자인 | 일관된 디자인 토큰, 숫자는 고정폭 폰트, 색 외의 수단으로도 정답/오답 구분 |
| N7 | 형상관리 | Conventional Commits로 개발 이력을 남김(AI 관련 표기 금지) |
